UI harness

Renders every overlay component against fixed fake data, with no extension and no chat site involved. This exists so the UI can be built and reviewed in parallel with the composer adapter — run npm run dev and open this file through the dev server.

Type here. Try an email like dana@example.com, a card 4111 1111 1111 1111, or paste a key.

Underlines are drawn in an overlay, not injected into this box — the same technique used on the real site. Solid means settled; dashed and faint means the detector is still tracking it. Click a solid underline to redact just that one item.
